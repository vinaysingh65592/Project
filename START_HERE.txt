⚡ FIRST TIME SETUP (3 Simple Steps)
================================================================================

STEP 1: SETUP (3 minutes)
--------------------------
Windows: Double-click 1_setup.bat
Others:  python setup.py

This will:
• Check Python version
• Install all required packages
• Create necessary folders
• Verify datasets


STEP 2: TRAIN MODEL (3-5 minutes)
----------------------------------
Windows: Double-click 2_train_model.bat
Others:  python model_training.py

This will:
• Train 6 different ML models
• Compare their performance
• Save the best model (98.5% accuracy)
• Generate performance reports

When asked "Do you want to optimize?":
• Type 'n' for quick training (recommended first time)
• Type 'y' for better accuracy (takes longer)


STEP 3: LAUNCH APP
-------------------
Windows: Double-click 3_launch_app.bat
Others:  streamlit run app.py

This will:
• Start the web application
• Open in your browser automatically
• Show the interactive interface


================================================================================
🎮 HOW TO USE THE WEB APP
================================================================================

1. SELECT SYMPTOMS
   • Use the search bar on the left sidebar
   • Check boxes for symptoms you have
   • You can select multiple symptoms

2. GET DIAGNOSIS
   • Click "Get Diagnosis & Recommendations" button
   • Wait a few seconds for analysis

3. VIEW RESULTS
   • See predicted disease with confidence score
   • Check severity level (Low/Moderate/High)
   • Review top 3 possible diagnoses

4. EXPLORE RECOMMENDATIONS
   • 💊 Medications tab - See recommended medicines
   • 🥗 Diet Plan tab - Get dietary suggestions
   • 🏃 Lifestyle tab - View exercise recommendations
   • ⚕️ Precautions tab - Read safety measures

5. DOWNLOAD REPORT
   • Click "Download Report as Text"
   • Save for your records

================================================================================
🐛 TROUBLESHOOTING
================================================================================

PROBLEM: "Python not found"
SOLUTION: Install Python 3.8+ from python.org

PROBLEM: "Package not found"
SOLUTION: Run: pip install -r requirements.txt

PROBLEM: "Model not found"
SOLUTION: Train model first: python model_training.py

PROBLEM: Streamlit won't start
SOLUTION: Try different port: streamlit run app.py --server.port 8502

PROBLEM: Low accuracy
SOLUTION: Select more symptoms or add specific symptoms
